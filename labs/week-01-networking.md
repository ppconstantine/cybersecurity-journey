# Week 1 — Networking Fundamentals

## Objective
Learn to identify local network settings, resolve domain names, test connectivity, and trace network paths.

## Tools
- Windows PowerShell
- ipconfig
- nslookup
- ping
- tracert

## Observations
- Local gateway: reachable
- Router ping: 0 ms average (rounded)
- Public IP ping: 13 ms average
- DNS lookup: successful
- Traceroute: destination reached in 11 hops; hop 9 showed unanswered probes

## Findings
An unanswered traceroute probe does not necessarily indicate a network outage. Later hops can still respond.
